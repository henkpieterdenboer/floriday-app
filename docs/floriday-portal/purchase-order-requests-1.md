# Order requests

## Target audience

* Customer organizations
* Supplier organizations

<br />
<br />

## Purpose

* Enables placing order requests by customer organizations on trade items and creating direct sales sales orders.

<br />
<br />

## Guidance

* Supplier can decide wether they accept order requests for each customer organization on the Floriday platform;
* Order requests can only be placed by customer when supplier accepts order request from the customer;
* When the supplier accepts the order request it will directly result in a sales order if the [system settings](https://customers.floriday.io/settings/system) are set to "Skip ready to order" in the customer portal;
* Order requests can only be placed on existing trade items by customer;
* When an order request matches with existing supply it will directly result in a sales order;
